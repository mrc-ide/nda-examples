# NDA Examples

This repo contains some examples using the [nda](https://github.com/dsharlet/array) package.

# To run

You can try and run the binaries in the [bin](./bin/) folder. If that doesn't work, you may need to compile the program. You can replace the {RCPP_EIGEN_INCLUDE_DIR} and {NDA_DIR} in the [gcc_flags](./gcc_flags) file and then run

```
./compile_and_run <file-name>
```
where `<file-name>` is one of the cpp files (without the `.cpp`), e.g. `iteration_and_access`.
